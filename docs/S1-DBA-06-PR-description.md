## Security Considerations

A custom GUC is not authentication. Only trusted backend code may derive actor
email from the validated session and revalidated account, set it locally in the
same transaction/client, and release the connection after commit/rollback. The
function cannot distinguish an arbitrary session-level SET from SET LOCAL;
reviewed backend integration and physical-connection tests enforce that contract.

Audit failures abort mutations. Existing hard-delete/truncate guards and browser
access restrictions remain. Password/setup/reset/session material is scrubbed
from snapshots; sensitive PKs fail without logging values. Maintained field-name
redaction and existing key-length limits need review before future attachment.
